# Zombie Prototype

Small Unity 6 prototype for testing zombie-horde interaction and first-person combat.

Start here:

- [Project handoff](Docs/PROJECT_HANDOFF.md) — current implementation, controls, architecture, balance, and continuation notes.
- [Design direction](Docs/DESIGN_DIRECTION.md) — product north star and prototype principles.
- [Development log](Docs/DEVELOPMENT_LOG.md) — chronological record of implemented changes and decisions.

Open `Assets/Scenes/SampleScene.unity` in Unity `6000.0.32f1`.

The user owns gameplay validation. Do not enter Play Mode or change balance based on autonomous testing unless the user explicitly requests it.
